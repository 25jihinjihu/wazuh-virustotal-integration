# Wazuh VirusTotal Integration

## Overview

This project demonstrates the integration of Wazuh SIEM with the VirusTotal API to provide automated malware detection and threat intelligence enrichment.

## Technologies Used

- Wazuh 4.x
- VirusTotal API v3
- Ubuntu 22.04 LTS
- Kali Linux
- OpenSearch Dashboard

## Architecture

Kali Linux Agent → Wazuh Manager → VirusTotal API → Wazuh Dashboard

## Features

- File Integrity Monitoring (FIM)
- Automated hash reputation checking
- Custom malware detection rules
- Real-time alert generation
- Dashboard visualization

## Testing

The implementation was validated using the EICAR test file, successfully generating high-priority alerts in Wazuh.
